## 1. 전체 업무 순서 (14단계)

```
[1단계] 결원 발생·충원 요청        → 부서 → 사무국
[2단계] 채용 기안(내부결재)        → 공고문(안) 확정
[3단계] 채용 일정 산출             → 접수마감·서류심사·면접·적격여부·근무개시
[4단계] 공고 게시 (6~8개 채널)     → 게시 증빙 보관
[5단계] 원서 접수 · 접수대장 기록
[6단계] 입사지원현황표 작성
[7단계] 서류심사 (부서 팀장)
[8단계] 1차 합격자 안내 공지 + 개별 연락
[9단계] 인사위원회 소집공문
[10단계] 면접 실시 · 면접평가표 작성
[11단계] 인사위원회 회의록 작성 · 최종 의결
[12단계] 결과 공고 + 개별 통보   → 적격자 없음이면 2단계로 재공고
[13단계] 임용 준비 (전력조회 · 경력조회 · 근로계약 · 이름표)
[14단계] 수습 관리 · 평가 · 정규직 전환
```

## 2. 단계별 상세 — 하는 일 / 문서 / 결재 / 보관

- **보관**: `01_기안·공고/`

### 2단계 · 채용 기안 (내부결재)
- **하는 일**: 공고 게시 전 내부결재를 받습니다. 기안문 본문에 **채용부서·모집인원·고용형태·채용조건·(긴급이면) 긴급 채용 사유·게시처·접수방법·채용기간**을 적습니다.
- **문서**: ① 채용공고 기안문(수신자: 내부결재) ② [붙임1] 채용공고(안) ③ [붙임2] 센터 소개
- **결재**: 담당 → 팀장 → 사무국장 → 소장 → 대표
- **시행번호**: 기안 상신 시 시행번호대장에서 다음 번호를 받아 `GR2026-A-○○○`으로 기재
- **보관**: `01_기안·공고/`

| ③ 2차 면접 | (예정) 서류심사 다음 평일 | 서류심사 합격자에 한함 |

- **추가 사용 이력**: 워크넷 · 잡코리아
- **문서**: 게시 증빙 캡처(사이트별 1장), 게시 URL 목록

### 6단계 · 입사지원현황표 작성
- **하는 일**: 접수 마감 후 전체 지원자를 한 표로 정리합니다(내부 보고 및 심사용).

- **본문 구성**: 인사말 → `<부서/팀명>` → 면접일시 → 장소 → 면접 대상자 → [유의사항] → [중요 안내]

- **유의사항 문구**: 10분 전 도착 / 담당자 전화·이메일 / 연락 미회신·미참석 시 자동 탈락 가능
- **입사지원현황표 반영**: `심사2` 칸에 면접 일시 기재(예: `8/24(월) 10:00 면접`)

## 4. 날짜 계산법 (앱 없이 손으로)

### 4-1. 접수마감일
1. **일반 공고**: 공고일 + 15일 / **긴급 공고**: 공고일 + 8일 (공고일 당일 포함해서 세지 말고, 공고일에 더합니다)
2. 그 기간 안에 **평일 공휴일**이 있으면 **그 일수만큼 마감일을 뒤로** 미룹니다.
3. 미룬 기간에 공휴일이 또 걸리면 **다시 그만큼 더** 미룹니다(연쇄 보정).

> 예) 2026-09-14 일반 공고 → 기본 마감 9/29 → 접수기간 중 평일 공휴일 9/24(추석연휴)·9/25(추석) 2일 → **마감 10/1**

### 4-2. 그 뒤 일정
- **서류심사일** = 접수마감 다음 날부터 세어 **첫 평일**(토·일·공휴일 제외)
- **2차 면접(예정)** = 서류심사 다음 날부터 세어 **첫 평일**. 소장·사무국장 등 **임원 일정이 있는 날은 건너뛰고** 그 다음 평일로 잡습니다.
- **3차 적격여부 확인** = 면접 다음 첫 평일 ~ 그 다음 첫 평일 (2일)
- **근무개시일** = 추후 협의(공고문에는 그대로 기재)

### 4-3. 수습 일정
- **수습 종료일** = 입사일 + 3개월 − 1일 (예: 9/1 입사 → 11/30)
- **근무평가 작성일** = 수습 종료일 − 31일 (예: 11/30 → 10/30)
- **작성(결재) 날짜** = 근무평가 작성일 + 1 평일
- **재계약일** = 수습 종료일 + 1년 − 1일

### 4-4. 공휴일 표 (센터 기준)

**2026년** — 1/1 신정 · 2/16~2/18 설날 연휴 · 3/1 삼일절 · **3/2 대체** · 5/1 근로자의 날 · 5/5 어린이날 · 5/24 부처님오신날 · **5/25 대체** · 6/3 지방선거 · 6/6 현충일 · 7/17 제헌절 · 8/15 광복절 · **8/17 대체** · 9/24~9/26 추석 연휴 · 10/3 개천절 · **10/5 대체** · 10/9 한글날 · 12/25 성탄절
